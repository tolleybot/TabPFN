The in-memory cache of built models is now enabled by default, holding two models so a classifier and a regressor can both stay resident. Repeated fits of the same checkpoint skip reconstruction and `load_state_dict`, and on GPU they also skip re-transferring the weights: a repeat fit of a 213 MB v3 checkpoint drops from 0.105 s to 0.003 s on CPU and from 0.215 s to 0.004 s on MPS. Predict time is unchanged, so end-to-end repeated fit/predict improves by 18% (CPU) and 26% (MPS); the first fit in a fresh process is unaffected. The cache pins the weights it holds, costing roughly 213 MB extra for a classifier-plus-regressor workload on v3 — set `TABPFN_MODEL_CACHE_SIZE=0` to restore the previous behaviour, or to any other positive integer to resize it. Offsetting that, the raw checkpoint is now released once its built model is cached, since `load_state_dict` copies and holding both duplicated the weights: live tensor bytes for a single v3 build drop from 425.3 MB to 212.6 MB.
